// TECHNICAL ARCHITECTURE · STUDENT INSIGHTS

01. Web Audio Procedural Synthesis

Traditional web games load hundreds of megabytes of compressed MP3 or OGG audio files. These games generate every gunshot, submarine ping, shockwave blast, and parry clang using raw OscillatorNode frequencies, BiquadFilter sweeps, and procedural white noise buffers on the fly.

02. Deterministic 2D Physics & ECS

Instead of bundling multi-megabyte physics runtimes, collision detection and kinematics use normalized vector math, mass-dependent knockback multipliers, poise thresholds, and component-based entity pools that execute at a solid 60 FPS.

03. Zero Third-Party Dependencies

Every game is built exclusively using standards-compliant HTML5, CSS3, and vanilla modern JavaScript. No webpack bundle bloat, no framework lock-in, and zero external CDNs—ensuring instant page loads and complete offline resilience.
